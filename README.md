## 📖 What is ilyOS?

ilyOS is the configuration I use daily, packaged into an AME Wizard playbook and ready to apply. This operating system aims for both speed and lightness, while still keeping minimalism and comfort of use in mind. Every change in the playbook comes from how I work with the system daily, that is, decisions based on real usage, not on the list of things that could be disabled for the mere fact of doing it.

## 💭 Philosophy

ilyOS follows the simple philosophy of having a computer configured and based on the interfaces and ways of working I've developed over the years using Windows. Just like Omarchy (an Arch Linux configuration), this playbook aims to generate an environment to my taste (and hopefully yours): app configurations, taskbar, interface and the rest of the sections I've been modifying, fixing and adjusting.

The idea of this project is to finish what I started at 16 and picked back up at 19, but giving it the approach of using playbooks, unlike the old versions of ilyOS, which modified the Windows 10/11 ISO directly, which was not scalable for me. If 5 people use this system and they like it, I consider myself satisfied; if my friends use it, I consider myself satisfied; and if I use it, I consider myself satisfied, because that way I don't have to configure my computer at every yearly reformat.

This project does not seek to be anyone's competition or to be the best playbook on the market. If you like systems such as [AtlasOS](https://atlasos.org) or [ReviOS](https://revi.cc), feel free to use them without problems, because they are much bigger and more dedicated projects than mine.

## 🔧 Requirements

- Most recent version of **Windows 11**. It is recommended that the system be completely formatted for the installation.
- **Compatibility**: this operating system can be used on **24H2**, as well as on **25H2** and **26H2**. The preferred version is **26H2**, as it is the one used for testing and the one that works best with ilyOS.
- **Official ilyOS playbook**. Please, never download a version outside of my download links.
- [AME Wizard](https://ameliorated.io), the application that runs the playbook.

## ⬇️ Installation

1. Download the latest *release* of the playbook (`ilyOSX.X.X.apbx`).
2. Download and open [AME Wizard](https://ameliorated.io).
3. Drag the playbook into the window, run it, follow the installation instructions and done.
